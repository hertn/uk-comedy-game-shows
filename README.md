## Install

**[Install in Stremio](stremio://hertn.github.io/uk-comedy-game-shows/manifest.json)**

Or open Addons in Stremio, choose Add addon, and paste:

```
https://hertn.github.io/uk-comedy-game-shows/manifest.json
```

The list appears on your Discover page as **UK Comedy & Game Shows**. Use the genre menu to narrow it down.

## How it stays current

New episodes of every listed show appear in Stremio on their own. Once a week, new UK panel, quiz, game and chat shows are found automatically and added to **New**. Approved ones move into the main list. The picks are UK only, with no US or Irish versions. Changes go live within about ten minutes.
